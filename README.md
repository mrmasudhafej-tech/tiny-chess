A chess engine in 3,980 bytes of Python: 0x88 negamax with PVS, iterative deepening, a transposition table, null-move pruning, LMR and quiescence, searching a fixed 100,000 nodes a move. Practice trials: mean Elo 1614, beating the sunfish 4 KB baseline (~1365).

## Run it

```sh
python3 main.py
```
